# MindVault 🧠

**A place to organize your study materials and prepare for exams.**

MindVault is a work-in-progress project that aims to make studying easier. It will let users organize files into folders, upload learning materials, and use AI to create reviewers and practice exams.

 🚧 **Status: Still under development**

## Features

Planned features include:

- 📁 **Folders** — Organize study materials in custom folders.
- 📄 **File uploads** — Store PDFs, DOCX files, and other supported formats.
- 🤖 **AI reviewers** — Turn uploaded materials into study reviewers.
- 📝 **Practice exams** — Generate questions to help you prepare for exams.
- 📚 **Study organization** — Keep your learning materials in one place.

*These features are still being developed and may change over time.*
